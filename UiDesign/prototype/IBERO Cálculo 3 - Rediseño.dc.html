UX audit

What's holding the current UI back

Overall impression

The app is functionally solid but visually inert — every screen is the same bordered box on the same dark grey, with no hierarchy between a hero number and a footer link. Nothing moves, nothing celebrates a win, and the gamified economy (Tokens, streaks, kudos) that's supposed to make the course feel like a game currently reads like an admin form. For a platform whose stated goal is to keep students opening it daily, that's the core gap.

What's already working

  • Dark, quiet ground with a single red accent — a good fit for a daily-use tool, not distracting during class.
  • Confirmation dialogs (Split Bill, purchases) show real before/after balance math — good trust-building detail worth keeping.
  • Copy is already inclusive and calm, matching the "professional consultancy" framing of the course.

Priority fixes

1. Give the Dashboard a hero, not a link list

Today "Inicio" is a stack of identical bordered rows to every page. The streak and token balance are the emotional core of the product — they deserve the top of the page, large numbers, a calendar, and a visible next milestone (mocked here).

2. Add motion to state changes

A token balance that jumps from 260 to 284 with no transition wastes the one moment students should enjoy. Count-up numbers, a streak-day checkmark that pops in, a progress bar that fills — small, cheap wins for "addictive" without gimmicks.

3. Fix the button hierarchy

Primary actions are currently solid red fills everywhere — purchase, confirm, register, admin links — so nothing stands out as *the* action on a screen. Reserve a filled red button for one primary action per screen; make everything else outlined or ghost.

4. Stop burying Admin inside the student dashboard

Admin links currently sit in the same list as student links, just recolored. As the teacher, you need a distinct "switch to admin" affordance — a role toggle in the nav, not three extra red rows at the bottom of your own dashboard.

5. Add icons and real visual grouping

Every link today is plain text in a box — Privilegios, Mis tickets, Movimientos, Décimas all look identical. Icons and a quick-access grid (mocked here) let students scan instead of read.

6. Design the file upload & preview flow now

This is planned but unbuilt. Since submissions are team-locked (first upload wins), the UI needs to show upload progress, a preview of the uploaded file (PDF/image inline, not just a filename), and a live "someone on your team is uploading" state — otherwise teams will double-submit or panic when a teammate's upload silently blocks theirs.

Screens not mocked here — quick notes

  • Privileges catalog: good structure (grouped by category); needs cost shown as a visual "afford / can't afford" state at a glance, not just a disabled button after the fact.
  • Tickets: the folio is the whole point (shown to the teacher in person) — it should be huge, high-contrast, and work at arm's length, ideally with a QR fallback.
  • Admin inbox: ten item categories in one flat queue will get overwhelming fast; group by priority visually (color bar, not just a label) and let high-priority items float regardless of age.
  • Registration: currently a plain form; since it's gated by rules acceptance and feeds straight into the profile test, treat it as step 1 of 2 with a visible progress indicator.
